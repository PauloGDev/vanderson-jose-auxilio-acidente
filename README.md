# Vanderson José Advogados Associados

Landing page jurídica sobre auxílio-acidente, acidente de trabalho e verbas rescisórias. Projeto React e Vite baseado na fundação modular do Template 1.

## Executar

```bash
npm run dev
```

## Validar e gerar

```bash
npm run lint
npm run build
```

A publicação está bloqueada até confirmação da OAB do profissional, domínio oficial, autorização de uso das imagens e revisão dos dados do escritório. A página permanece com `noindex` enquanto essas pendências estiverem abertas.
